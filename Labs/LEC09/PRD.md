# PRD: 소닉 애니메이션 뷰어 (Sonic Animation Viewer)

> 본 문서는 `PRE-PRD.md`에 명시된 요구사항을 바탕으로 작성된 개발 문서입니다.

## 1. 개요

- **목적**: `sonic-sprite.png` 스프라이트 시트에 담긴 소닉의 모든 동작(걷기, 달리기, 구르기 등)을
  순서대로 자동 재생하는 뷰어 프로그램 제작
- **개발 언어**: Python
- **라이브러리**: pico2d
- **파일명**: `sonic_anmation_viewer.py` (PRE-PRD 명시, 단일 파일로 작성)
- **위치**: `Labs/LEC09/`

## 2. 입력 리소스

- `Labs/LEC09/sonic-sprite.png`
- 시트 상단에 "Classic Sonic Sprites" 타이틀과 하단에 제작자 크레딧이 포함되어 있어, 실제 캐릭터
  프레임 영역만 추출해야 함
- **중요**: 이 시트는 각 행(동작)마다 프레임 개수와 프레임 폭이 서로 다른 **불규칙한 스프라이트
  시트**임 (예: 정지 자세는 좁고, 달리는 자세는 넓음). LEC08/LEC10 실습처럼 고정 크기 그리드로
  단순 분할이 불가능하므로, 동작별 프레임 좌표를 별도로 조사해 수동으로 매핑해야 함

## 3. 기능 요구사항

| ID | 요구사항                                                                                  |
| -- | ----------------------------------------------------------------------------------------- |
| F1 | 스프라이트 시트에 포함된 모든 동작을 순서대로 재생한다                                    |
| F2 | 각 동작은 해당 동작의 프레임 시퀀스를**5회 반복 재생**한다                          |
| F3 | 한 동작의 5회 반복 재생이 끝나면**1초간 정지**한다                                  |
| F4 | 1초 정지 후 다음 동작으로 넘어간다                                                        |
| F5 | 모든 동작을 한 바퀴 다 재생하면 처음 동작으로 돌아가**무한 반복**한다               |
| F6 | 화면 대비 캐릭터가 잘 보이도록 충분히**확대**해서 그린다                            |
| F7 | ESC 키, Q 키, 또는 창 닫기 버튼으로 프로그램을 종료할 수 있다 (LEC10`handle_events` 패턴 준용) |
| F8 | 화면 해상도는 **1200x800 픽셀**로 고정한다 (`open_canvas(1200, 800)`)                        |

## 4. 비기능 요구사항

- 코드는 **단일 파일**(`sonic_anmation_viewer.py`)로 작성
- 한 번에 완성하지 않고 **단계별로 구현**하며, 각 단계마다 커밋 가능한 상태를 유지
- 개발 단계는 **최소 20단계 이상**으로 세분화 (아래 6장 참고)

## 5. 설계 개요

### 5.1 데이터 구조

동작별 메타데이터를 아래와 같은 구조로 정의한다 (실제 좌표값은 개발 4~5단계에서 이미지를 분석해
채워 넣음).

```python
ACTIONS = [
    {
        "name": "walk",
        "y": 0,            # 시트 내 세로 시작 좌표
        "frame_h": 48,      # 프레임 높이
        "frames": [         # 프레임별 (x, width)
            (0, 32), (32, 34), ...
        ],
    },
    # ... 동작별로 추가
]
```

프레임 폭이 동작마다 다르므로, 동작별로 프레임 목록을 `(x, width)` 쌍의 리스트로 관리한다.

### 5.2 재생 로직 (의사 코드)

```python
while True:                      # F5: 전체 무한 반복
    for action in ACTIONS:       # F1: 모든 동작 순회
        for repeat in range(5):  # F2: 동작별 5회 반복
            for frame in action["frames"]:
                draw_frame(frame, scale=ZOOM)
                delay(FRAME_DELAY)
        delay(1)                 # F3: 1초 정지
```

### 5.3 확대 (F6)

`Image.clip_draw(sx, sy, sw, sh, x, y, w, h)`에서 목적지 크기(`w, h`)를 원본보다 크게 지정하여
확대한다. 확대 배율은 상수 `ZOOM`으로 관리하고, 그려지는 위치는 캔버스 중앙으로 고정한다.

### 5.4 화면 해상도 (F8)

`open_canvas(1200, 800)`으로 캔버스를 연다. 캐릭터는 캔버스 중앙인 `(600, 400)`을 기준으로
그린다.

## 6. 개발 단계 (최소 20단계, 단계별 커밋)

1. `sonic_anmation_viewer.py` 빈 파일 생성, `pico2d` import만 작성
2. `open_canvas(1200, 800)` / `close_canvas()`만으로 1200x800 빈 캔버스가 뜨고 닫히는지 확인 (F8)
3. `load_image('sonic-sprite.png')`로 시트를 로드하고, 원본 그대로 화면에 1회 그려 로드 확인
4. 이미지 뷰어 등으로 스프라이트 시트를 분석하여 동작(행)별 대략적인 y좌표/높이 조사
5. 각 동작의 프레임별 x좌표/너비를 조사하여 `ACTIONS` 자료구조 초안 작성 (좌표는 미완성 상태 허용)
6. 첫 번째 동작(예: walk) 중 프레임 1개만 `clip_draw`로 정확히 잘라 그리는 테스트
7. 테스트 결과를 보고 해당 동작의 좌표값을 보정
8. 첫 번째 동작의 전체 프레임을 순서대로(키 입력 또는 루프로) 하나씩 그려보며 좌표 검증
9. 프레임 인덱스를 0~N-1로 순환시키는 애니메이션 루프 작성 (`delay` 기반 프레임 전환)
10. `ZOOM` 상수를 도입해 `clip_draw`의 목적지 크기를 확대 적용 (F6)
11. 확대된 캐릭터가 캔버스 중앙에 그려지도록 좌표 계산 로직 작성
12. 두 번째 동작의 좌표를 조사해 `ACTIONS`에 추가하고, 동일 방식으로 단일 프레임 테스트
13. 특정 동작 하나를 재생하는 `play_action(action)` 함수로 로직 추출(리팩터링)
14. `play_action` 내부에서 프레임 시퀀스를 **5회 반복 재생**하도록 로직 추가 (F2)
15. 5회 반복 재생이 끝난 뒤 `delay(1)`로 1초 정지 추가 (F3)
16. `ACTIONS` 리스트를 순서대로 순회하며 각 동작에 대해 `play_action`을 호출하는 메인 루프 구성 (F1)
17. 모든 동작 재생이 끝나면 처음부터 다시 반복되도록 `while True`로 감싸기 (F5)
18. LEC10 패턴을 참고해 `handle_events()` 작성 및 적용, ESC/Q/창닫기로 종료 가능하게 함 (F7)
19. 남은 동작들의 좌표를 모두 조사하여 `ACTIONS`에 채워 넣기 (전체 동작 커버)
20. 전체 동작을 한 바퀴 돌려보며 좌표가 어긋난 동작을 찾아 보정
21. 현재 재생 중인 동작 이름을 콘솔 로그로 출력해 디버깅 편의성 확보
22. 매직넘버 정리, 상수/함수 분리 등 코드 정리(리팩터링)
23. 처음부터 끝까지 전체 사이클을 재생해 최종 QA 수행

## 7. 완료 기준 (Acceptance Criteria)

- 프로그램 실행 시 스프라이트 시트에 포함된 모든 동작이 누락 없이 순서대로 재생된다
- 각 동작은 정확히 5회 반복 재생 후 1초 정지한다
- 마지막 동작까지 재생되면 다시 처음 동작부터 반복된다
- 캐릭터가 화면에서 충분히 크게(확대되어) 보인다
- ESC 키, Q 키, 또는 창 닫기로 정상 종료된다
- 화면 해상도가 1200x800 픽셀로 고정되어 있다
- 코드가 단일 파일로 구성되어 있다
